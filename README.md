# Long-Term Memory

Personal knowledge base — auto-synced from Claude Code sessions.

## Structure

```
archive/
├── YYYY-MM-DD/
│   ├── *.md          # Memory files from that date
│   └── INDEX.md      # Snapshot of MEMORY.md for that date
MEMORY_INDEX.md        # Master index of all memories
```

## Usage

This repo is auto-committed daily at 22:00 via Windows Task Scheduler.
